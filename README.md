## 🧩 About

The **Online Food Ordering System** is a full-stack web application built with **ASP.NET (C#)** and **SQL Server**.  
It provides a platform for users to order food online, while administrators can manage menu items, categories, and customer orders efficiently.

This project demonstrates CRUD operations, database connectivity, authentication, and web-based interaction between users and the server.

---

## 🌟 Features

✅ User registration and login  
✅ Browse food items and categories  
✅ Add to cart and checkout  
✅ View order history  
✅ Admin dashboard for management  
✅ Secure and scalable backend  
✅ Responsive and user-friendly UI
